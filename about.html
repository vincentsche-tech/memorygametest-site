About Memory Test

Memory Test started with a simple belief: everyone can improve their memory with practice. We built free, fun tools to help people measure and train their working memory — because a better memory means a sharper mind.

What We Do

We offer free memory games (card matching, number recall) and informative guides about photographic memory, eidetic memory, and cognitive training. Everything is free, no signup, no download.

Our Promise

  • Free forever. No paywalls, no signups.
  • Private. All games run in your browser; nothing is uploaded.
  • Honest. We're clear that our tests are for fun and self-improvement, not medical diagnosis.
